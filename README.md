# FirefoxThemeExt

This is the repo for The Fighting Mong00ses' project 1, a Firefox extension that allows users to
group themes for easier access.

Initialized 01/22/26

## Local checks

- Run everything : 'npm run check'
- Auto-format: 'npm run format'

## Git hooks

This repo uses pre-commit hooks to format/lint staged files automatically.
After pulling, run 'npm install'
